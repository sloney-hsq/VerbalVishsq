# 4K 横屏工作台前端重构

用户已要求直接实施，确认主屏为 3840×2160 横屏。沿用隔离 worktree；只改前端呈现及对应说明，保留用户正在整理的研究材料与任务池。

## 设计与约束

保持克制的浅色科研工作台：蓝灰背景、白色图卡、深色文字、单一蓝色操作强调。桌面采用左侧分析区、右侧可收起的对话栏。头部显示会话状态与麦克风入口，分析区显示标题、数据范围和图数。4K 可用宽度增加时同步改善字体、绘图区与间距，而不是增加一排狭小图卡。1920×1080 和 1366×768 仍可使用；更窄屏采用上下布局。

不改变模型、语音策略、分析工具、数据、排序、统计口径、dashboard revision 或研究条件。不新增语音文字对照或实验功能。聚合值、色标、缺失及类别顺序不得因视觉调整变化。

## Task 1: 工作台与对话栏

主代理负责 Dashboard.vue、App.vue、新增 workspaceTheme.css、VisualCheckApp.vue、预览入口及文档。保留当前会话、录音、转写和动作反馈逻辑。对话栏支持展开/收起，窄窗口可用；为无会话/无图状态提供清楚提示。预览必须复用生产 Dashboard，不制造伪真实 provider 输出。

## Task 2: 图卡与图表

子代理负责 ChartSlot.vue、chartLayout.js、chartGrid.js、chartGrid.css、chartSpecs.js、specFactory.js 及相关图表测试。先读根 agent.md 和 worktree AGENTS.md。改造图卡头部、语义徽标、警告、分页与绘图区，适配 4K。建议三列宽屏图卡，复杂矩阵或分面跨两列；根据可用宽度合理提高图表文字与高度，避免热力图横向无限拉长。全局图表顺序、数据域和色标保持稳定。修复发现的实际布局缺陷，不加入语义交互或伪按钮。可使用主代理提供的 --vv-* CSS token，均需 fallback。

## Task 3: 验收

前端 node 测试、构建；真实图表预览在 3840×2160、2560×1440、1920×1080、1366×768 浏览器检查。重点核查整体溢出、卡片重叠、图表裁切、热力图分页与全局尺度、对话展开收起、错误状态和窄屏。浏览器 viewport override 检查后恢复。真实语音链路没有实测就不声称验证。

## 所有权与审查

Task 1 与 Task 2 文件不重叠，共享界面为图卡接收的 availableWidth 与 --vv-* token；不改 Vue props 的既有含义。根目录和 worktree 的已有文档删除、README/PROGRESS 修改和任务池不属于本次工作。实现子代理不再派生代理、不提交或推送；整合后由主代理验证并安排只读审查。
